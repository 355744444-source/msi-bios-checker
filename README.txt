# 微星主板 BIOS 下载工具 v2.5.3

> 江苏振远智能科技有限公司 · MSI Motherboard BIOS Downloader

单文件 Windows 桌面工具：内置**微星官网全部在售主板目录**（约 500 款，含中国站特供补录）。**三栏浏览器式布局**：左栏「导航」按 平台 → 芯片组 两级树，中栏「型号」列出当前芯片组下的主板，右栏「明细」显示该型号全部 BIOS 历史版本与选中版本详情；选中即查、一键下载（进度条 / SHA-256 校验），保存目录与操作按钮横跨底部工具条。新目录更新入口在设置面板「立即更新目录」。

## 技术要点

- **绕过 Akamai 防护**：微星官网由 Akamai CDN 保护，普通 Python `urllib` / `requests` 直接访问会被 403。本工具使用 `curl_cffi` 的 `impersonate="chrome124"` 模式伪造 Chrome TLS 指纹，可稳定访问官方 API 与下载直链。
- **DNS 自愈**（v2.3.3 增补）：运营商 / 路由器递归 DNS 偶发无法解析 Akamai 域（`www.msi.com` / `download.msi.com`）时报 curl error 6/28。工具自动改用 DoH（RFC 8484：阿里 `223.5.5.5` → 腾讯 DNSPod `1.12.12.12`，IP 直连不依赖系统 DNS）重试；仅 DNS 类错误触发，其余错误路径不变。覆盖目录 / 型号查询 / 中国站补全 / BIOS 下载全部请求。
- **官方接口**（非爬 HTML）：
  - `GET /api/v1/product/getProductTagList?product_line=mb`  → 芯片组分类（29 组）
  - `GET /api/v1/product/getProductList?product_line=mb&id[]=<tag>` → 按芯片组的型号
  - `GET /api/v1/product/support/panel?product=<slug>&type=bios`  → 该型号 BIOS 列表
- **目录构建**：全量 463 条 → 过滤官网占位/配件（xx、TPM 模块等）→ 按 29 个芯片组逐个归类 → Intel/AMD 分桶；官网未分类的零散老型号收进「其他」。**中国站补全**（v2.1.0 增补）：每次 fetch_catalog 末尾自动拉 msi.cn 全量（374 款）比对补录大陆特供/渠道型号 38 款（B760M BOMBER / PRO B760M-X II / Z790MPOWER / X870 GAMING PLUS WIFI BULK / B450 TOMAHAWK MAX 等），按 chipset 名（含 `X870E/X870` 斜杠拆分）归入，归属不到入「其他」。共 **499 款**。
- **双站 BIOS 回退**（v2.1.0 增补）：MsiApi.get_bios_panel 改为先查 msi.com，全球站无数据自动回退 msi.cn（中国特供/渠道型号专属）。状态栏标注「数据源：微星中国站」；打开官网支持页对应切换 msi.cn；下载直链走 download.msi.cn（同样支持 Range 206）。
- **断点续传**：下载直链支持 `Range` 头（206 / Accept-Ranges）。v2.2.0 起取消 / 失败**保留 `.part` 分片**（旧版删除，等于每次重头下）；服务端返回 200（不支持 Range）时自动丢弃分片全量重下，并对已有分片补算 SHA-256 增量摘要，不额外全量重读文件。
- **状态持久化**（v2.2.0）：窗口几何 / 上次型号 / 保存目录 / 目录树展开状态写入 `msi_bios_checker.cfg`；越界坐标自动拉回屏幕内，脏数据一律回退默认（整文件损坏也不抛异常）。配置文件与目录缓存均走「`flush()` + `fsync()` 后 `os.replace`」的原子写，断电不留半截 JSON。
- **网络策略**（v2.2.0）：DoH 解析器带健康记忆（连续失败 ≥3 次降队尾，成功清零）；重试退避带上限与随机抖动（抖动夹在上限之内，真实峰值不超过设定值）；启动期的目录后台刷新加 400–4000ms 随机延时，避免同批机器同一时刻打上游。
- **界面字体与对齐**（v2.2.1）：界面字族不写死，由 `_ui_font_family()` 探测本机后按
  `Microsoft YaHei UI → Microsoft YaHei → Noto Sans SC → PingFang SC → SimHei → SimSun`
  优先级回退（换机器不会掉到 Tk 默认字体）；全部字号为像素级负值，由 `S()` 按 DPI 缩放，
  行高与列宽公式同步跟随。目录树缩进归零 —— 左栏所有文字落在同一条左边界上。
- **进度行宽度**（v2.2.2）：进度条左侧的文案格宽**不写死**，而是用两条上界样例
  （`PB_TXT_FULL` / `PB_TXT_SHORT`）按标签真实字体（`FONT_S`）实测像素宽换算成
  `ttk.Label` 的字符格；**降级阈值与标签格宽共用同一个实测值**（`_pb_label_px`），
  判据是「进度行宽 − 12px 内边距 − 标签格宽 ≥ `PB_BAR_MIN`(280px)」。
  这样窄窗口（1100）正确压成短文案，而默认 1200×780 始终显示完整文案 —— 不再出现
  「明明够宽却被降级」。实测 1100/1200/1280/1400/1600 × 目录加载前后共 10 组，
  完整文案下进度条实测 300–757px，均高于保底宽。
- **弹簧动效内核**（v2.3.0）：`class Spring(damping, response)` 用解析解
  （`ω₀ = 2π/response`，过冲 `exp(−ζπ/√(1−ζ²))`）直接算任意时刻位移，不再依赖固定帧数；
  另保留一条半隐式欧拉数值积分路径做**交叉验证**（实测数值积分会引入额外数值阻尼 ——
  ζ=0.55 的过冲由 12.63% 掉到 10.86%，所以运行时只走解析解）。七个令牌
  `SPR_VALUE / SPR_ENTER / SPR_BANNER / SPR_PRESS / SPR_SHAKE / SPR_PULSE / SPR_EMPTY`
  覆盖值过渡 / 入场 / 出退场 / 按压 / 回摆 / 脉冲六类语义。静止判据是「位移 + 速度」
  双阈值（`SPR_EPS_X` / `SPR_EPS_V`），满足即停表 —— **空闲时 Anim 调度器不占 CPU**。
- **布局宽度策略**（v2.3.0）：左栏宽度按三级优先
  `用户拖拽值 > 布局区 × LEFT_RATIO(0.30) > 型号名实测所需`，钳制区间
  `[SPLIT_MIN_LEFT(280), min(LEFT_MAX(470), 布局区 − SPLIT_W(10) − CAT_RIGHT_MIN(620))]`；
  右栏保底 620px。**注意口径**：`_body_width()` 返回的是**含 padding 的控件宽**，
  比例项与钳制项都必须先减 `BODY_PAD_X × 2`，否则「30%」实际约 30.8%、且钳制上限偏大 40px
  （旧版就漏减了，因为夹紧分支从未被触发所以没现形，加了分隔条立刻暴露）。
- **Tk 的 pack 按「调用顺序」分配空间**（v2.3.0 踩坑）：`side="right"` 不是"优先"，只是方向。
  空间不足时**后 pack 的控件先被压扁**（实测数据源徽章被压到 `w=6px`，文字在数据里但一像素都没画）。
  要让某个控件优先占位，必须**先 pack 它**。另：`<Configure>` **不会**因内部内容变化而触发，
  依赖内容变化的重算必须挂 `StringVar.trace_add` 或手动调用。
- **离线自检**：EXE 支持 `--check`，无 GUI 自检目录接口 / 目录构建 / BIOS 面板 / 下载直链（结果写 `msi_bios_checker_selftest.log`）。

## 运行环境

- Windows 10 / 11（x64）
- 无需 Python 环境，单文件 EXE 自包含
- 网络：能访问 `msi.com` 即可（首次建目录需联网，之后有缓存）；系统 DNS 解析 msi.com 失败时自动走 DoH 备用解析，无需手动配置

## 使用方法

1. 双击 `微星主板BIOS下载工具.exe` 启动；首次启动自动联网构建目录（约十几秒，之后秒开）
